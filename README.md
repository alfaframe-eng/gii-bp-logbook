# GII Mighty Tree BP Logbook

**Gwaram Impact Initiative | Community BP Monitoring for Gwaram LGA, Jigawa**

Live Demo: https://alfaframe-eng.github.io/gii-bp-logbook/

> Screening and education only. Does not diagnose hypertension.

An offline-first web app that runs in any browser. Volunteers can record BP, print PDF report, export CSV, and collect anonymous Hausa feedback. All data stays on device.

Tech: HTML, CSS, JS, LocalStorage
Built by Alamin Isah Muhammad - Gwaram Impact Initiative
